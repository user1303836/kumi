# Kumi 的 Logic Pro 适配器：M2、M3

- 原始 Logic M2 读取器的应用端适配器。通过 `logic_read` 读取工程、轨道、片段、音符、插件、发送、标记和速度；FOCUS 提供 Channel Strip、Piano Roll、Tracks、Routing 四种视图。
- 需要 macOS 上的 Logic Pro 12。桥接程序连接已打开的 Logic，不向 Logic 安装组件，也不要求重启 Logic。程序、已构建的辅助程序和连接信息放在 `KUMI_HOME/bridges/logic/bridge/logic-kumi`。
- 请在系统设置 → 隐私与安全性 → 辅助功能中允许运行 Kumi 的应用。设置流程轮询已认证桥接程序的权限状态；对话框或其他桌面的状态与权限不足分别显示。
- 使用已连接 Logic 的 Apple 包标识打开已保存的工程。可读取工程、所选项目和录音状态。M3 提供16种修改和3项走带操作，并有 HISTORY 和按值恢复的撤销。Logic 没有整批撤销块，音量、声像、静音、独奏、待命、速度和旁通不进入 Logic 自身撤销历史。听音、渲染、目标、脚本和变更追踪仍未启用；可从文件查找资料库并搜索手册；尚未提供预设加载和原生浏览器访问。
- 发布文件包括 `logic-kumi`、`kumi-logic-hands-*` 和 `version`。源码检出需预先构建原生桥接程序及辅助程序。`KUMI_LOGIC_BRIDGE_SOURCE` 可指定现有发布格式文件夹；设置流程不构建原生代码。
- 隔离测试使用本地夹具与工程打开操作的替身，不启动真实 DAW，也不要求辅助功能授权。原生录制回放与实际 Logic／应用验收属于独立检查。

实机自动修改检查须在临时工程中使用 `accept_logic --changes --scratch-confirmed`；撤销失败可能留下修改。录制回放不代表当前实机验收。

新增和已删除轨道、已删除标记需要在 Logic 撤销历史中手动撤销；Kumi 不按标题猜测并执行原生撤销。标记的新增或移动若缺少原始 Text 等必要信息，也需手动撤销；事后显示该列无法恢复旧值。只有原始行和列表身份信息完整时才按值恢复，`discard` 也不能绕过未知身份。已确认的手动撤销修改以 Kept 保留在 HISTORY，默认撤销不会跳过它去撤销更早的修改。不确定的修改保持不确定。不会仅凭标题推断标记、音符或结构修改已由原生撤销恢复。
