# Logic Pro lab, 2026-10-18

Status: complete for M0 (the go/no-go per channel). Scope: what macOS gives Kumi to read and change
Logic Pro, measured on this machine, before any crate is designed around a guess.

| | |
| --- | --- |
| Logic Pro | 12.3.1 (6682), `com.apple.logic10`, `/Applications/Logic Pro.app`, App Store build (sandboxed) |
| macOS | 26.6.1 (25G76), Apple Silicon |
| Project | a scratch copy of a one-track project (one audio region, 160 BPM, 4/4), in the session's scratchpad; nothing of the producer's was changed |
| Probes | throwaway Swift tools: an Accessibility dumper and actor, a key poster, a virtual Mackie Control, an OSC listener and sender, a Core Audio process tap; kept out of the repository |
| Permissions | Accessibility was granted to the terminal app the session runs in (TCC attributes the grant to the responsible app, as with Hands); the process tap recorded without any prompt |

## Verdict per channel

| Channel | Verdict | What was measured |
| --- | --- | --- |
| Accessibility reads | go | The whole project reads from the AX tree: control bar (tempo, time and key signature, playhead bar and beat, transport state), track headers (name, mute, solo, record, monitoring, pan 0–127, volume 0–233 with "0.0 dB" descriptions), regions (name, start and end in the help text, selected state, border and loop handles), the Inspector's channel strips (name, mute, solo, record, fader with dB, pan −64..63, peak, automation mode, group, output, send slot, insert slots with bypass, open and list buttons, input, EQ, setting, input gain), the Event List (one row per event: position as a four-segment scrubber, status, channel 1–16, note number 0–127 named like "C3", value with a text description, length as a four-segment scrubber; a Delete action per row; a Create new Event button), the Piano Roll (one layout item per note named by position and pitch, selectable and movable), the Marker List (position, name, length, marker text), the Signature List (time and key), the Undo History (number, action, date, time, with Undo and Redo buttons), the Control Surface Setup window, open panels and sheets. The window's `AXDocument` gives the project path. |
| Accessibility writes | go, with rules | Buttons and checkboxes press (Play started playback; Stop stopped it; the Create new Event button added an event). Text fields take a value and need `AXConfirm` to commit (renaming a track through the Inspector's name field updated the header and the Mackie LCD). The Tempo slider moves by one per set, so exact tempo needs the text entry or the list. Menu items press only while Logic is the active app. Pop-up buttons must not have their children read: it opens their menu. |
| Key commands | go, with rules | Posting key events to Logic's pid works for unmodified keys at any time (Return, arrows) and for modified combinations only while Logic is active (Opt-Cmd-A made a track, Cmd-Z undid it, Cmd-S saved, Opt-' made a marker). Modifier keys are posted as their own events. The producer's active bindings are readable from the preferences, the factory presets are XML plists, and the English command names are plain strings in `Logic.framework`, with localized copies in its `.lproj` folders. |
| Open and save panels | go, with a twist | The App Store build is sandboxed, so its panels belong to `com.apple.appkit.xpc.openAndSavePanelService`: keys posted to Logic never reach them. Posting Cmd-Shift-G to that service's pid opened the go-to-folder sheet, whose field took the path through AX; the Import button then imported a MIDI file, creating a software instrument track and a MIDI region. |
| Mackie Control | go | Logic scanned the virtual "Kumi Logic" ports within a second, sent device queries for Logic Control, Logic Control XT, Mackie Control, its extender and the C4, installed the surface on the first reply (no challenge, no restart, no dialog), and streams feedback: the LCD with 7-character track names, select, mute, solo, record and transport LEDs, the timecode display, fader positions and V-Pot rings. The select button selected a track (LCD and Inspector followed). Transport buttons did nothing, with two devices installed on the same ports by the first probe; to be rechecked with one. Answering every device query installs every model: a bridge must answer only as a Mackie Control. |
| OSC | no, for now | Logic listens on UDP 7000 (IPv6 socket) and advertises `_osc._udp` under the Mac's name with TXT `AppleLogic=LogicProX mfk=1`; `Logic.framework` browses `_osc._udp` too. Advertising a service named "TouchOSC LogicPad" or "LogicPad" and sending `/ping`, `/1/bank+`, `/1/time` to port 7000 from it got no reply and installed nothing. The LogicPad layout's addresses (five pages: mixer, sends and inserts, plug-in parameters with names and values, Channel EQ, 24 parameters) are in `TouchOSC.bundle`. Parked: AX and Mackie cover its uses; revisit for continuous plug-in moves. |
| Project file | partial | The documented framing walks the whole file (460 records). Region and channel names sit in `AuRg` and `AuCO` records. The one UUID in the sample sits in a `GenM` record and survives a save, but two other projects carry no UUID, so it is not a project id. `MetaData.plist` gives tempo, signature, key, sample rate and the file lists. `ProjectInformation.plist` gives the saving version. |
| Process tap | go | A tap on Logic's pid during playback captured 48 kHz stereo float with peak 0.39 and RMS −22.8 dBFS, with no prompt on this machine. |
| AX notifications | no | Observers on the application, the control bar and the Tracks area received nothing across play, stop, selection and track creation. The bridge polls. |
| Busy states | go | A modal panel makes `AXMainWindow` an `AXDialog` ("Import"); a confirmation shows as an `AXDialog` focused window with its buttons; sheets appear as `AXSheet` children. |
| Windows and Spaces | caution | While Logic's Space is not the current one, `AXWindows` is empty, `AXMainWindow` is nil and the window server lists nothing on screen, although the Window menu still lists the project window. Activating Logic or choosing the window in the Window menu brings it back. The helper must tolerate that and never assume a window list. |
| Undo | go | Each change is one Undo History row with a plain action name ("Create Track", "Renaming", "Create Marker", "Import", "Create Event", "Change Tempo"); the Edit menu's Undo and Redo titles name the top step. |

## Clean-up

Of the control-surface devices the first probe installed on the "Kumi Logic" ports, one was
removed through the Setup window (select the icon, Delete key, confirm the dialog); the icon
view then reported "No Device" for what remained, and once the probes stopped no "Kumi Logic"
MIDI port was left. Worth a glance in Logic Pro > Control Surfaces > Setup… next time Logic opens.
The scratch project stays in the session's scratchpad with unsaved lab edits; Logic was left
running.
