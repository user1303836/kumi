# 機能マトリクス

[English](../en/CAPABILITY_MATRIX.md) · [简体中文](../zh-CN/CAPABILITY_MATRIX.md) · 日本語

ブリッジが Live の各領域で何をカバーしているか、どのチャンネルが作業を行うか、変更をどう取り消すか、本物の Live でテストしたかどうかをまとめます。ツールそのものは[ユーザーガイド](USER_GUIDE.md)に、これらをもとに作られた Kumi 独自の変更ツールは [Kumi が Set を変更するしくみ](KUMI_CHANGES.md)に記載しています。

## マトリクスの読み方

**チャンネル**は作業が行われる場所です：

| チャンネル | 内容 |
| --- | --- |
| Remote Script | `AbletonMcpBridge`。Live の中で、Live の Python API を通じて動作します |
| 拡張機能 | Kumi の Live 拡張機能。Live の Extension Host で動作します（Live 12.4 以降） |
| Willington | オプションのネイティブプロバイダー。バインディングのある Live ビルド用です：macOS ARM64 の 12.4.15b4 と b5（[Willington 連携](WILLINGTON_INTEGRATION.md)） |
| ブリッジ | ブリッジのプロセスそのもの。Live を使いません |

ツールが提供されるのは、接続先の Live にそのツールに必要な操作があり（ブリッジは接続時にそれを知ります）、かつデプロイメントポリシーがそれを許可している場合だけです（[ユーザーガイド](USER_GUIDE.md)を参照）。

**取り消し：** *正確*は、その後ほかの何もその状態を変えていない限り、`live_undo` が変更前に記録した状態を元に戻すことを意味します。*保持*は、ブリッジでは元に戻せないものの、Live 自身の取り消しなら戻せることを意味します（クリップ、トラック、シーン、ロケーターの削除、範囲のクリア）。*取り消し不可*は、ブリッジもツールも元に戻す方法を約束しないことを意味します（クリップのクロップ、すべてのエンベロープのクリア、デバイスの削除、マクロのランダム化などのラック操作）。*なし*は取り消すものがないことを意味します：再生、一時的な操作、読み取りです。詳しくは [Live の安全性](LIVE_SAFETY.md)を参照してください。

**本物の Live** は、その領域が本物の Live で最後に試された場所を示します。*受け入れテスト*は Live 12.4.15b5 とブリッジ 1.0.63 での Kumi の受け入れテスト（`accept_live`）、*以前の実行*は Live 12.4.15 beta とブリッジ 1.0.0〜1.0.65 でのそのほかの実行、*7月の実行*は Live 12.4.5b8 とブリッジ 0.1.0 での、ブリッジの最初の実行です。*未実施*はテストのみを意味します。テストは macOS、Linux、Windows 上で、偽の Live オブジェクトに対して実行されます。記録の一覧は[実装状況](IMPLEMENTATION_STATUS.md#エビデンス)にあります。

## 予約済みの操作

操作レジストリには、ブリッジが決して実行しない操作がいくつかあります。それらは理由を示して拒否され、どのツールも提供しません：

- `arrangement.automation.create`、`.delete`、`.point.insert`、`.point.delete`：アレンジメントのオートメーションの編集
- `audio.comp.read`：Live のコンプエディターに表示されるとおりのコンプ領域
- `project.new`、`.open`、`.save`、`.save-as`、`.collect`、`.export`、`.bounce`：機能リソースでは制限として報告されます
- `session.discover`：別名で、`discover` が処理します

`browser.preview.start` と `browser.preview.stop` も[機能マニフェスト](../evidence/capability-manifest.json)では予約済みとされていますが、Live の Browser がプレビューできるときには Remote Script が実行し、ブリッジは `live_browser_preview` を提供します。テイクレーンの作成と、テイクレーン内での MIDI クリップの作成は、レジストリと Remote Script にはありますが、どのツールも提供していません。

## Live の API が提供しないもの

Live 12.4.15b5 の Python API の全数調査（[LOM 監査](../evidence/lom-audit.md)）で、すべてのクラスとメンバーを Remote Script と照らし合わせました。残っているのは、Live の Python API からも Extensions SDK からも手が届かないもの、または対象外のものです：

| 提供されないもの | 代わりにあるもの |
| --- | --- |
| Set の保存、オープン、書き出し。Collect All and Save | 保存済みの Set の検証済みバックアップ。単一のファイルのプロジェクトへのインポート。保存は Live で行ってください。 |
| ミックスやステムの書き出し。フリーズとフラット化 | オーディオトラック自身のクリップのオフラインレンダリング。Resampling を通じた録音 |
| グループトラックの作成 | — |
| アレンジメントのオートメーションの編集 | その読み取り。セッションのクリップのエンベロープ |
| マクロやモジュレーターのパラメータへのマッピング | Wavetable と Drift のモジュレーションマトリクス。Willington を通じたマクロのマッピング |
| Follow Actions | Willington を通じて |
| コンプの編集、テイクレーンの削除や試聴 | レーンとコンプの読み取り、レーンの名前の変更、レーンへのオーディオ |
| ノートごとの MPE（プレッシャー、スライド、ノートごとのチューニング） | 確率、ベロシティのばらつき、リリースベロシティ、ミュート |
| プラグイン独自のウィンドウや内部の状態 | そのパラメータ、プリセット、ウィンドウの開閉 |
| 再生中のトラックの音声 | Resampling を通じたキャプチャ。オフラインレンダリング |
| Browser の類似検索、Packs、Cloud | Live のライブラリデータベース：タグ、種類、プラグインの一覧 |
| 環境設定、オーディオと MIDI のセットアップ、ライセンス。ステム分離。ビデオトラック | — |
| Set を開き直しても変わらないオブジェクトの ID | 参照が有効なのは一回の接続の間だけです。ディスカバリーで読み直します |

意図的に対象外としているもの：Push などのハードウェアサーフェス（ブリッジは Control Surface ですが、生の MIDI は読みません）、一般的な OSC、ウェブ、シリアル、センサーとの接続（リアルタイムコントロールはループバックのみ）、外部の Link ピアと Link Audio、ブリッジ内の Max for Live デバイス。Max for Live デバイスは Kumi 自身が作ります。[Kumi ガイド](KUMI_GUIDE.md#max-for-live-デバイスを作る)を参照してください。
