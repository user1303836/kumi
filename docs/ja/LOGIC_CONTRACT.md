# Logic Pro ブリッジ契約（M2）

macOS の Logic Pro 12 以降で、`kumi --daw logic` または `/daw logic` から明示的に選びます。実験段階のため自動選択しません。`kumi --daw logic bridge` は Kumi 自身のフォルダーにブリッジを置き、開いている Logic を再起動しません。セットアップで求められたら、システム設定でヘルパーのアクセシビリティを許可します。接続だけではこの手順は完了しません。

プロジェクト、トラック、リージョン、選択中のリージョンのノート、プラグイン、センド、マーカー、テンポを読みます。FOCUS はチャンネルストリップ、ノート、タイムライン、ルーティングを表示します。録音状態と保存済みプロジェクトのパスが分かり、以前確認した保存済みプロジェクトを開けます。変更、取り消し、聴く機能、ゴール、スクリプト、前回からの差分、ライブラリー探索は未対応です。ノートを読むには対象リージョンだけを選択しておきます。Kumi は選択を変えません。通常の起動では MIDI ポートを作りません。

[契約と制限](LOGIC_CONTRACT.md)も参照してください。記録の再生テストは現在の Logic での実機検証ではありません。開発者はスクラッチプロジェクトで `accept_logic` のサンプルを明示的に実行し、新しい検証結果を保存できます。

ワイヤーメソッドは `ping`、`status`、`focus`、`read`、`snapshot`、`focus_body` の六つです。`status.permission` は未許可時に `accessibility`、通常時は `null`。`busy` は `false` または `modal`・`away`・`loading` です。サンプルレートは最大 64 KiB の通常 XML ファイル `Alternatives/000/MetaData.plist` のみから非同期に読み、シンボリックリンク、バイナリー形式、不明な値は `null` にします。明示的な `--mcu` は Logic にコントロールサーフェス設定を残す可能性があります。詳細な JSON の形とヘルパー操作は [英語の契約](../en/LOGIC_CONTRACT.md) を参照してください。2026-10-18 のラボ記録は過去の証拠であり、この移植版の新しい実機測定ではありません。
